# 🆘 Emergency Login - Quick Reference

## 🎯 What is Emergency Login?

Emergency Login is a **backup authentication method** that allows you to login using your **Student ID and password** when face authentication is not available.

## 🔑 Your Credentials

```
Username: Your Student ID (e.g., 24CS1001)
Password: The password you created during registration
```

## 📝 When to Use Emergency Login

Use emergency login when:
- ✅ Wearing a mask or face covering
- ✅ Poor lighting conditions
- ✅ Camera not working
- ✅ Face recognition fails
- ✅ Emergency situations

## 🚀 How to Use

### Registration (One-Time Setup)

```
Step 1: Generate Student ID
   ↓
Step 2: Enter Your Details
   ↓
Step 3: Create Emergency Password ⚠️ NEW
   • Username = Your Student ID (auto-set)
   • Create your password (6+ chars, letters + numbers)
   • Confirm password
   ↓
Step 4: Capture Your Face
   ↓
✅ Registration Complete!
```

### Login (Daily Use)

#### Option 1: Face Authentication (Faster) 🔐
```
1. Go to "Face Authentication"
2. Capture your face
3. ✅ Login!
```

#### Option 2: Emergency Login (Backup) 🆘
```
1. Go to "Face Authentication"
2. Select "Emergency Login"
3. Enter Student ID
4. Enter Password
5. ✅ Login!
```

## 💡 Quick Tips

### ✅ DO
- Use face authentication first (faster)
- Keep password secure
- Use password manager
- Remember your Student ID
- Use emergency login when needed

### ❌ DON'T
- Share your password
- Use simple passwords (123456)
- Write password on paper
- Share your Student ID
- Forget to logout

## 🔒 Security

### Password Requirements
- ✅ Minimum 6 characters
- ✅ Must contain letters
- ✅ Must contain numbers
- ✅ Example: `john2024`, `mary123abc`

### Password Storage
- 🔐 Never stored in plain text
- 🔐 SHA-256 hashing with salt
- 🔐 Unique salt per user
- 🔐 Secure verification

## 🆘 Troubleshooting

### "Invalid Student ID or password"
**Solution:**
1. Check Student ID format (e.g., 24CS1001)
2. Verify password (case-sensitive)
3. Try face authentication
4. Contact admin for password reset

### "Password too weak"
**Solution:**
1. Use 6+ characters
2. Include letters AND numbers
3. Example: john2024, mary123abc

### "Face not detected"
**Solution:**
1. Switch to emergency login
2. Enter Student ID + password
3. ✅ Login successful!

## 📞 Need Help?

### Forgot Password?
1. Try face authentication instead
2. Contact administrator for reset

### Can't Login?
1. Try both methods (face + password)
2. Check credentials
3. Contact IT support

### Registration Issues?
1. Follow all 4 stages
2. Ensure password meets requirements
3. Contact support if stuck
